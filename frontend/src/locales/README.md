# 화면 번역

- `ko.json`, `en.json`, `ja.json`에서 같은 키의 문구를 함께 관리합니다.
- 컴포넌트는 `useTranslation()`의 `t('newChat')`처럼 키로 문구를 가져옵니다.
- 숫자나 제목은 `t('deleteConfirmation', { title })`처럼 전달합니다. 문장 순서가 언어마다 달라질 수 있으므로 문장을 조각내서 연결하지 않습니다.
- 강조나 링크가 포함된 문장은 `Trans`를 사용합니다. 세 파일의 `{{변수}}`와 태그 이름을 동일하게 유지하세요.
- 언어 선택은 기능 페이지에 있습니다. 기본값은 한국어이고, `gureum_language`에 선택값을 저장합니다. 다른 탭에도 반영됩니다.
- 서버가 반환하는 알려진 안내 문구는 `translateMessage()`로 표시합니다. 서버가 문구를 바꾸면 한국어 원문도 함께 갱신해야 합니다. 아직 등록되지 않은 서버 문구는 원문을 표시합니다.
- 사용자 입력, 대화 제목과 실제 AI 답변은 번역하지 않습니다. 요금의 통화도 원화 그대로 유지합니다.
- `npm run check:i18n`으로 키 누락, 빈 문구, 보간 변수와 태그 일치를 검사합니다.
